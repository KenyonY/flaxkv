# FlaxKV TTL 持久化功能

## 功能说明

FlaxKV 现在支持 TTL（生存时间）的持久化存储，这意味着即使在程序重启后，之前设置的 TTL 计时器仍然会继续工作，键会在到期后自动过期。

## 主要改进

1. **TTL 信息持久化**：TTL 信息现在会保存到数据库中，而不仅仅是保存在内存中。
2. **跨程序运行**：即使程序终止并重新启动，TTL 计时器也会继续工作，确保键在正确的时间过期。
3. **自动清理过期键**：重新打开数据库时，会自动检查并清理已过期的键。

## 实现细节

1. **TTL 信息存储**：
   - 使用特殊前缀 `__ttl_info__:` 创建专门的键来存储 TTL 信息
   - 每个 TTL 信息包括原始键和过期时间戳

2. **持久化机制**：
   - 设置 TTL 时，同时将信息保存到数据库
   - 删除 TTL 时，同时从数据库中删除相应的 TTL 信息
   - 数据库打开时，加载所有未过期的 TTL 信息

3. **过期检查**：
   - 程序重启时，加载 TTL 信息并检查是否已过期
   - 已过期的键会被自动删除
   - 未过期的键会继续倒计时，从上次设置的时间点继续计时

## 使用示例

```python
from flaxkv2 import FlaxKV
import time

# 创建/打开数据库
db = FlaxKV("my_db", "./data")

# 设置键值对
db["key1"] = "value1"

# 设置TTL（10秒后过期）
db.set_ttl("key1", 10)

# 查看当前TTL
print(f"当前TTL: {db.get_ttl('key1')}")  # 输出：当前TTL: 9.9998...

# 关闭数据库（模拟程序终止）
db.close()

# 等待几秒（模拟时间流逝）
time.sleep(5)

# 重新打开数据库（模拟程序重启）
db = FlaxKV("my_db", "./data")

# 再次查看TTL，会发现已经减少了等待的时间
print(f"重启后TTL: {db.get_ttl('key1')}")  # 输出：重启后TTL: 4.9998...
```

## 注意事项

1. 由于 TTL 基于系统时间，如果系统时间被修改，可能会影响 TTL 的准确性。
2. TTL 信息也会占用一定的存储空间，特别是当设置了大量带 TTL 的键时。
3. TTL 检查会在键被访问时进行，过期的键会在访问时被删除。
4. 每隔一段时间（默认60秒）会进行一次全量清理，删除过期的键。
